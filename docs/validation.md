Notes:

- NYC smoke is classified **MODEL_LEADS**: CAMS AQI is extreme while FIRMS
  smoke_pressure stays low. That is treated as signal (regional haze), not
  data corruption — the integrity layer does not flag it as an error.
- The corrupted-feed fixture resolves to **UNUSABLE** via critical findings
  (POWER sentinel, heat-index math break, RH/PM range errors). The assess
  path refuses a verdict and falls back to last-good cache when available.
